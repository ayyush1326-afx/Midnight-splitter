# 🌙 Midnight Splitter — Preprod Deployment Guide

This guide walks you through deploying the **MidnightSplitter** Compact smart contract to the **Midnight Preprod** testnet (the public pre-production explorer at `explorer.preprod.midnight.network`).

---

## Prerequisites Checklist

| Requirement | Status | Notes |
|---|---|---|
| **WSL2** | Required on Windows | Compact compiler is Linux/macOS only |
| **Lace Wallet** (Midnight mode) | Required | Set to Preprod network |
| **tNIGHT tokens** (faucet) | Required | For funding the wallet |
| **tDUST** (from delegation) | Required | Used as gas for contract deployment |
| **Docker** (optional) | Recommended | For running a local proof server |
| **Node.js 18+** | Required | For the deployment scripts |

---

## Step 1 — WSL2 Setup (Windows only)

If WSL2 is not already installed:

```powershell
# In PowerShell as Administrator
wsl --install
wsl --set-default-version 2
# Reboot if prompted
```

Open a **WSL2 terminal** (Ubuntu) for all subsequent steps.

---

## Step 2 — Install the Compact Compiler

Inside your WSL2 terminal:

```bash
# Install the Compact CLI (includes the compactc compiler)
curl --proto='=https' --tlsv1.2 -LsSf \
  https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh

# Reload shell
source ~/.bashrc   # or source ~/.zshrc

# Download and activate the latest compiler version
compact update

# Verify
compact --version
compact compile --version
```

> [!NOTE]
> The `compact` CLI manages compiler versions similar to `rustup`. Running `compact update` downloads the latest `compactc` binary.

---

## Step 3 — Fund Your Midnight Preprod Wallet

1. **Install Lace Wallet** from [lace.io](https://www.lace.io)
2. In Lace settings, **switch to Midnight mode** and select **Preprod** network
3. Copy your wallet's **shielded address**
4. Visit the **Midnight Faucet**: [https://midnight-tmnight-preprod.nethermind.dev/](https://midnight-tmnight-preprod.nethermind.dev/)
5. Request `tNIGHT` tokens (testnet tokens, free)
6. In Lace, **delegate** your `tNIGHT` to generate `tDUST` — this is the native fee token

> [!IMPORTANT]
> Deployment requires `tDUST` for transaction fees (generated by delegating `tNIGHT`). Allow ~10 minutes after delegation for `tDUST` to appear.

---

## Step 4 — Configure Environment Variables

In the **project root** (on Windows, open in your WSL2 terminal):

```bash
# Copy the example env file
cp .env.example .env

# Edit .env and set your seed phrase
nano .env
```

Set `MIDNIGHT_SEED_PHRASE` to the **24-word mnemonic** of your funded Preprod wallet:

```env
MIDNIGHT_SEED_PHRASE=word1 word2 word3 ... word24
```

> [!CAUTION]
> **Never commit `.env` to git.** It contains your wallet seed phrase. The `.gitignore` already excludes it.

---

## Step 5 — Compile the Compact Contract

In your WSL2 terminal, from the project root:

```bash
# Compile the Compact contract (produces ZK proving keys + circuit IR)
compact compile contracts/midnight_splitter.compact --output dist/contracts

# Expected output files in dist/contracts/:
#   midnight_splitter.contract          ← main contract bundle
#   midnight_splitter_split_equal.zkir
#   midnight_splitter_split_weighted.zkir
#   midnight_splitter_split_custom.zkir
#   midnight_splitter_verify_solvency_proof.zkir
```

Alternatively, if `compact` is in your WSL2 PATH and you run from Windows PowerShell:

```powershell
npm run contract:compile
```

---

## Step 6 — (Optional) Run a Local Proof Server

The `verify_solvency_proof` circuit requires a proof server for ZK proof generation. The public Preprod prover (`https://prover.preprod.midnight.network`) can be used directly, or you can run locally:

```bash
# Pull and run the Midnight proof server (Docker)
docker pull ghcr.io/midnightntwrk/midnight-proof-server:latest
docker run -d -p 6300:6300 ghcr.io/midnightntwrk/midnight-proof-server:latest

# Then set in .env:
# MIDNIGHT_PROVER_URL=http://localhost:6300
```

> [!TIP]
> Using a local proof server is faster and avoids rate limits on the public prover during high traffic.

---

## Step 7 — Deploy the Contract

**Option A — Automated (recommended):**

```powershell
# From Windows PowerShell in the project root
npm run contract:deploy
```

The script will:
1. Validate your `.env` configuration
2. Health-check Preprod endpoints
3. Query the latest block height
4. Invoke `compact deploy` via WSL2 bridge
5. Write the contract address to `contracts/deployed-address.json`
6. Auto-update `src/services/midnightContract.ts`

**Option B — Manual via WSL2:**

```bash
# In WSL2 terminal, from project root
export MIDNIGHT_SEED_PHRASE="word1 word2 ... word24"

compact deploy \
  --network preprod \
  --contract dist/contracts/midnight_splitter.contract \
  --indexer https://indexer.preprod.midnight.network/api/v1/graphql \
  --prover  https://prover.preprod.midnight.network \
  --gas-limit 10000000

# Copy the contract address from the output, then run:
node scripts/deploy-preprod.mjs --record <CONTRACT_ADDRESS>
```

**Option C — Dry run (validate without submitting):**

```powershell
node scripts/deploy-preprod.mjs --dry-run
```

---

## Step 8 — Verify Deployment

```powershell
npm run contract:verify
```

This queries the Preprod indexer GraphQL and displays:
- ✅ Contract address found on-chain
- Public ledger counters: `contract_version`, `total_splits_executed`, `total_volume_settled`
- Latest block info

You can also verify manually on the **Midnight Preprod Explorer**:

```
https://explorer.preprod.midnight.network/contract/<YOUR_CONTRACT_ADDRESS>
```

## Troubleshooting

### `compact: command not found` in WSL2
```bash
# Ensure ~/.local/bin is in PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
compact --version
```

### Out of gas error during deployment
Increase gas limit in `.env`:
```env
MIDNIGHT_GAS_LIMIT=20000000
```
Or ensure your wallet has enough `tDUST` (try requesting more from the faucet and re-delegating).

### Prover unreachable
```bash
# Check public prover
curl -I https://prover.preprod.midnight.network

# Or start local Docker prover
docker run -d -p 6300:6300 ghcr.io/midnightntwrk/midnight-proof-server:latest
```
Then set `MIDNIGHT_PROVER_URL=http://localhost:6300` in `.env`.

### `deployed-address.json` shows PENDING
The deployment script did not complete successfully. Check the error output and try again, or deploy manually (Option B above).

### Re-deploying (force)
```powershell
node scripts/deploy-preprod.mjs --force
```

## Deployed Contract Circuits

| Circuit | Visibility | Description |
|---|---|---|
| `initialize` | Public | Sets admin address and contract version |
| `calculate_equal_split` | Public | Pure helper: computes share + dust |
| `verify_solvency_proof` | ZK (private witnesses) | Proves balance ≥ required without revealing balance |
| `split_equal` | Public + ZK | Atomic equal split to N recipients |
| `split_weighted` | Public + ZK | Weighted basis-point split (10,000 bps = 100%) |
| `split_custom` | Public + ZK | Custom per-recipient amounts |
